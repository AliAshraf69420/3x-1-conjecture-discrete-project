# How to run program
1. Install python -if it's not already on your device-
2. In a cli, navigate to the program directory most likely will be in `3x-1-conjecture-discrete-project/Code/` or `3x-1-conjecture-discrete-project\Code\` depending on your system.
3. Type:
```bash 
python ThreeXplus1.py
```
4. Enter starting number for the conjecture.
